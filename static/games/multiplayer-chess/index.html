Multiplayer Chess

Create a private room, share the six-character code, and play chess with a friend. The browsers connect directly with WebRTC, so the game itself is peer-to-peer.

  • ✓ No accounts
  • ✓ Two players per room
  • ✓ Moves validated in both browsers

Start a private game

The host gets a six-character code. Send it to one friend; the person who creates the room and the person who joins must both keep this page open.

1

Create a room

Enter a nickname and create a room. The server gives you a private six-character code that expires after 30 minutes.

2

Share the code

Send the code to one friend. They enter it on this page and the room accepts the first person who joins.

3

Play directly

The server helps the browsers exchange connection details, then the chess moves travel directly over WebRTC.

Important limitations
  • No STUN or TURN server is used. The direct connection may work on the same local network or in favourable network setups, but it is not guaranteed across different networks.
  • Some browsers hide local IP addresses behind mDNS names. If the connection fails, try both devices on the same Wi-Fi network or use two tabs on one computer.
  • The signaling server stores only the room record and the temporary WebRTC offer/answer. It never receives chess moves or game history.
  • Refreshing or closing a tab destroys the peer connection. Create or join a new room to play again.
  • Both browsers validate chess moves locally, but this is not server-side anti-cheat. A modified client can cheat.
